# 🎮 Minecraft Chinese with Pinyin (v1.0.0)

Welcome to the **v1.0.0 official release** of the **Minecraft Chinese Pinyin Resource Pack**! 

This resource pack seamlessly enriches your Minecraft experience by displaying accurate **Hànzì (Chinese characters)** alongside **Pīnyīn with tonal diacritics**, while keeping all slash commands in pristine native English.

Whether you are learning Chinese, practicing character recognition, or playing on international servers, this pack is designed to provide full immersion without the frustration.

---

## ✨ Release Highlights

* 🇨🇳 **Full Hanzi + Pinyin Annotations**: Every block, item, mob, biome, advancement, and UI label features clear Chinese characters with tonal Pinyin (e.g., `钻石剑 (Zuànshí Jiàn)` for Diamond Sword, `苦力怕 (Kǔlì Pà)` for Creeper).
* ⚡ **Untranslated Native Commands**: Never fight command parsers or break your muscle memory again! Essential command syntax (`/give`, `/teleport`, `/locate`, `/gamerule`, argument helpers) remains in English.
* 🌏 **Multi-Dialect Support**:
  * 🇨🇳 **Simplified Chinese** (`zh_cn`)
  * 🇭🇰 **Traditional Chinese - Hong Kong** (`zh_hk`)
  * 🇹🇼 **Traditional Chinese - Taiwan** (`zh_tw`)
  * 📜 **Literary / Classical Chinese** (`lzh`)
  * 🇺🇸 **English Fallback** (`en_us`): Enjoy Chinese + Pinyin even if your client language is set to English!
* 🎨 **Custom Pack Icon**: Includes a 256×256 high-resolution pack icon for quick identification in the Minecraft Resource Packs menu.
* 📦 **Minecraft Version Compatibility**: Pack Format **32** (designed for Minecraft Java Edition **1.20.5+** / **1.20.6** / **1.21+**).

## 🚀 Quick Install

1. Download **`Minecraft-Chinese-Pinyin-v1.0.0.zip`**.
2. Open Minecraft Java Edition and navigate to **Options** ➔ **Resource Packs...**.
3. Click **Open Pack Folder**.
4. Drag and drop `Minecraft-Chinese-Pinyin-v1.0.0.zip` into the opened folder.
5. In Minecraft, move the pack from **Available** to **Selected** (right side) and click **Done**.
6. Set your language to Chinese (Simplified, Traditional, or Classical) or keep English (US).
