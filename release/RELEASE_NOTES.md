# Minecraft Chinese with Pinyin (v1.0.0)

Welcome to the v1.0.0 release of the Minecraft Chinese Pinyin Resource Pack.

This resource pack displays Chinese characters (Hanzi) alongside tone-marked Pinyin across Minecraft: Java Edition, while keeping slash commands in standard English.

---

## Release Highlights

* **Full Hanzi and Pinyin Annotations**: Items, blocks, mobs, biomes, advancements, and UI labels feature Chinese characters paired with tonal Pinyin (e.g., `钻石剑 (Zuànshí Jiàn)` for Diamond Sword, `苦力怕 (Kǔlì Pà)` for Creeper).
* **Untranslated Commands**: Command syntax (`/give`, `/teleport`, `/locate`, `/gamerule`, argument helpers) remains in English.
* **Broad Dialect Support**:
  * Simplified Chinese (`zh_cn`)
  * Traditional Chinese - Hong Kong (`zh_hk`)
  * Traditional Chinese - Taiwan (`zh_tw`)
  * Classical Chinese (`lzh`)
  * English Fallback (`en_us`): View Chinese with Pinyin even when playing on English client settings.
* **Custom Pack Icon**: Includes a 256x256 pack icon for the in-game Resource Packs menu.
* **Compatibility**: Pack Format 32 (designed for Minecraft: Java Edition 1.20.5+ / 1.20.6 / 1.21+).

## Installation

1. Download `Minecraft-Chinese-Pinyin-v1.0.0.zip`.
2. In Minecraft: Java Edition, navigate to **Options** -> **Resource Packs...**.
3. Click **Open Pack Folder**.
4. Drag and drop `Minecraft-Chinese-Pinyin-v1.0.0.zip` into the opened folder.
5. In Minecraft, move the pack from **Available** to **Selected** and click **Done**.
6. Set the in-game language to Chinese (Simplified, Traditional, or Classical) or keep English (US).
